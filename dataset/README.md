# Dataset placement

The original IPVS WAV recordings are not bundled here. Obtain them from the authorized source and confirm its terms before use or redistribution. Place the cohort folders here (or update the dataset root in the notebook). Keep participant recordings out of a public GitHub repository unless the data license and consent explicitly allow public redistribution.

`train/`, `validation/`, and `test/` are empty placeholders only. The actual participant-level partitions are generated by the notebook after the dataset is placed. The saved split counts are documented in the repository README; participant identifiers are not fabricated here.
