# Upload to GitHub

1. Sign in to GitHub and choose **New repository**.
2. Repository name: `parkinsons-voice-analysis`.
3. Choose Public only if the papers, code, and included assets may be shared publicly. Do not upload restricted participant audio.
4. Create the repository.
5. Choose **Add file → Upload files** and drag the contents of this project folder (not the outer folder) into the browser; alternatively use Git from your computer.
6. Commit with message: `Add Parkinson's voice analysis research project`.
7. Copy the repository URL and paste it into your submission form.
